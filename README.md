# 🛡️ ShieldIoT: AI-Sec Defense Lab & IoT Security Workspace

> **Hackfest 2.0 • Track 1 (Open-Source AI & Tooling) & Track 2 (Best Use of Gemma 4)**  
> **Live Demo:** [shield-iot.netlify.app](https://shield-iot.netlify.app)

---

## 🛑 1. Problem Statement
As IoT devices (such as CCTV cameras, Wi-Fi routers, and smart controllers) proliferate across home and enterprise networks, they introduce massive security attack surfaces. Developers frequently leak hardcoded API keys and credentials on GitHub, while security teams lack a unified, intuitive workspace to audit firmware code, track device risk postures, and safely practice threat response.

---

## 🎯 2. Hackathon Tracks
* **Track 1:** Open-Source AI & Tooling (Providing developer-first security utilities and code sanitizers).
* **Track 2:** Best Use of Gemma 4 (Leveraging Google's lightweight edge AI model as an intelligent security guardrail).

---

## 💡 3. Our Solution: ShieldIoT
**ShieldIoT** is a fully deployed, interactive security workspace and digital twin simulator. It empowers security analysts and developers with a centralized platform to:
* Manage hardware inventories via structured **Device Passports**.
* Scan and sanitize IoT firmware code using the **Code Security Auditor**.
* Simulate network attacks and practice incident response safely using the **Attack Simulator**.
* Translate technical risks into plain-English recommendations using the **Gemma AI Assistant**.

---

## 🌟 4. Why This Solution?
* **Proactive Security:** Catches hardcoded credentials and vulnerabilities *before* code ever touches GitHub.
* **Safe Simulation:** Allows security teams to practice threat isolation and DDoS defense in a 100% safe, virtual digital-twin environment.
* **Radical Transparency:** Clear disclosure of demo-mode states and AI limitations via our dedicated **Trust Center**, avoiding false security claims.

---

## 🚀 Key Features & Modules
* **Overview Dashboard:** Real-time visibility into posture scores, tracked devices, and active threat trends.
* **Device Passport:** Metadata review and structured hardware identity profiling.
* **Code Security Auditor:** Static analysis for C/C++, Python, and Arduino firmware to detect hardcoded secrets and insecure endpoints.
* **Attack Simulator:** Virtual node simulation for testing DDoS mitigation and device isolation workflows.
* **JSON Reporting:** Instant export of security audit logs and session history.

---

## 📋 Presentation Flow
1. **Overview:** Explain posture scoring and tracked IoT assets.
2. **Device Passport:** Showcase metadata review and structured profiling.
3. **Code Security Auditor:** Demonstrate vulnerability detection and secure code patterns.
4. **Attack Simulator:** Trigger a virtual network threat and execute device isolation.
5. **Trust Center:** Conclude with transparency, safety, and human-in-the-loop oversight.
